# いのちの1万年すごろく 〜縄文から令和へ〜

中学校 技術・家庭科（技術分野）「C 生物育成の技術」のガイダンス用すごろくです。
1班1台のChromebookで、2〜7人で遊びます。

- ゴールはなく、ぐるぐる回るコースを決めた年数（8・12・16年）だけ回ります。スタート地点の「収穫祭」を通るたびに、持っている施設の収入が入ります。
- 班で「発展度」を上げると、縄文 → 弥生 → 奈良・平安 → 鎌倉・室町 → 江戸 → 明治〜昭和 → 平成・令和 と時代が進み、景色・施設・技術カード・クイズが切り替わります。
- クイズは、各時代に関係する生物育成の技術（育成環境、肥料、土、栽培・飼育・養殖の方法、新しい技術など）を問います。
- 施設マスでは、3問中2問正解でその時代の施設（農地・畜産・水産）を買えます。「大規模」にすると収入2.5倍・災害の被害2倍。
- 大勝負マスでは、安全策か勝負（ルーレット・難問）を選べます（ハイリスク・ハイリターン）。
- 1年ごとに班全体に影響するニュースが起きます（洪水・台風・伝染病・赤潮・猛暑など／豊作・大漁・関税の緩和・補助金など）。持っている施設の種類によって影響が変わります。
- 2年ごとに「村の会議」があり、班の全員で多数決をして村の進め方を決めます。
- ちがう種類の施設を組み合わせると収入アップ（農地＋畜産＝循環型農業×1.3、3種類で×1.5）。最後の2年は収入2倍です。
- キャラクター（ガイチュウ・ジュウガイ・ガイビョウ）は、すれちがった人にうつります。
- 最後に個人の順位と班の得点を表示します（提出はありません）。
