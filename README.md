# いのちの1万年すごろく 〜縄文から令和へ〜

中学校 技術・家庭科（技術分野）「C 生物育成の技術」のガイダンス用すごろくです。
1班1台のChromebookで、2〜7人で遊びます。

- 縄文時代から出発し、班で「発展度」を上げると時代が進みます（縄文 → 弥生 → 奈良・平安 → 鎌倉・室町 → 江戸 → 明治〜昭和 → 平成・令和）。
- 時代ごとに、盤面の景色・できごと・クイズ・施設・技術カードが切り替わり、第1次産業の発展と変化を学べます。
- チャンスマスでは、3問中2問正解でその時代の施設を手に入れられます。
- 最後に個人の順位と班の得点を表示します。一人ずつ「組・番号・名前」とふりかえり（2問・各30字以上）を入力し、班まとめてGoogleスプレッドシートへ提出します。
- スプレッドシートには「1万年すごろく」（班の結果）と「1万年すごろく_ふりかえり」（一人1行）の2つのシートができます。班の結果は、クラスの班ランキングに表示されます。
